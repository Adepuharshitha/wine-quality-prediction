**Project Title**

Wine Quality Prediction using Machine Learning

**Problem Statement**

Wine quality depends on several physicochemical properties. This project predicts wine quality based on these properties using machine learning models.

**Dataset**
UCI Wine Quality Dataset
Features include:
Fixed acidity
Volatile acidity
Citric acid
Alcohol
pH
Sulphates
**Technologies Used**
Python
Pandas
NumPy
Scikit-Learn
Matplotlib
**Model Used**
Decision Tree
Random Forest
**Results**
Performed exploratory data analysis to understand feature relationships.
Built classification models to predict wine quality.
Evaluated model performance using accuracy metrics.
